# Security policy

## Reporting a vulnerability

Use this repository's GitHub **Private Vulnerability Reporting** flow. Do not
include credentials, tokens, signing secrets, account IDs, internal endpoints, or
other sensitive deployment information in public issues, pull requests, or logs.

If Private Vulnerability Reporting has not yet been enabled, do not publish a
public issue; contact the repository owner through a private channel and ask for a
secure reporting path.

## Supported versions

Security fixes are evaluated for the current `main` branch. Deployers are
responsible for securing their own AWS, Slack, Anthropic, and local credentials.
